# My Project

Full-stack authentication and post management project built with Next.js, Express, TypeScript, MongoDB, Docker, and HTTP-only cookie authentication.

## Tech Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod
- Axios
- Framer Motion

### Backend

- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- Zod
- JWT
- HTTP-only cookies

### DevOps

- Docker
- Docker Compose
